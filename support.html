サポート

このアプリの使い方、不具合、Apple版の購入復元、端末内翻訳モデル、音声認識、ウィジェット、Apple Watchに関する案内です。

共通の確認事項

  • 音声認識を使うには、マイクの許可が必要です。
  • 音声認識や翻訳は、端末、OS、選択した言語、必要な翻訳モデルの準備状況によって利用できない場合があります。
  • 作成したカード、お気に入り、設定、カテゴリの順序は端末内に保存されます。iPhone、iPad、Mac間では自動同期されません。iPhoneでお気に入りにしたフレーズは、ペアリング済みのApple Watchに共有されます。
  • 端末を変更した場合、カードや設定は新しい端末で再作成してください。Apple Watchに表示するお気に入りは、ペアリングしたiPhoneで設定します。

iOS / iPadOS / Apple Watch版について

  • iOS/iPadOS版では、設定で Google ML Kit または Apple Translate を選択できます。Google ML Kit を選んだ場合は、設定画面から対応言語モデルの一覧確認、個別ダウンロード、一括ダウンロードができます。
  • Google ML Kit の翻訳モデルの初回ダウンロードや更新には通信が必要です。Apple Translate は必要な言語データをシステム経由で管理します。
  • iOS/iPadOSの音声認識は Apple の Speech framework、購入と復元は Apple の StoreKit を使用します。
  • プレミアム機能が反映されない場合は、アプリの設定画面または購入画面から「購入を復元」をお試しください。
  • 購入や復元が完了しない場合は、App Store で使用している Apple ID、通信状態、スクリーンタイムや購入制限を確認してください。
  • お問い合わせ時は、端末名、iOS/iPadOSバージョン、発生した画面、再現手順、入力言語と翻訳先言語、表示されたエラーメッセージを添えてください。Apple Watchの問題では、ペアリングしているiPhoneの機種とOSバージョンもお知らせください。
  • iPhone/iPadのホーム画面ウィジェットでは、お気に入り、すべて、または選んだカテゴリのカードを表示できます。Apple Watchでは、iPhoneでお気に入りにしたフレーズを表示・拡大できます。
  • iPhone/iPadのホーム画面ウィジェットでは、お気に入り、すべて、または選んだカテゴリのカードを表示できます。Apple Watchでは、iPhoneでお気に入りにしたフレーズを表示・拡大できます。

macOS版について

  • macOS版の翻訳は Apple Translate のみを使用します。
  • Google ML Kit と、その翻訳モデルをダウンロードする機能は macOS版には含まれません。
  • 必要な言語データは macOS の Apple Translate が管理します。利用できる言語や初回ダウンロードの可否は、Mac と Apple Translate の対応状況によって異なります。

Android版について

  • Android版は Android の音声認識機能を使用します。対応環境ではオンデバイス音声認識を優先します。
  • オンデバイス音声認識が利用できない端末や言語では、オンライン音声認識を利用する場合があります。
  • 翻訳は Google ML Kit Translation を使用します。翻訳モデルのダウンロードや更新には通信が必要です。
  • Android版には Google Play Billing によるアプリ内購入、サブスクリプション、購入復元機能はありません。
  • お問い合わせ時は、端末名、Androidバージョン、発生した画面、再現手順、選択していた入力言語と翻訳先言語を添えてください。
